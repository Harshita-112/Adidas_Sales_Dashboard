# Adidas Sales Dashboard

## Project Overview

This project focuses on analyzing Adidas sales data using **Microsoft Excel**. The dataset contains 10,000 sales records covering different retailers, regions, products, states, and sales methods from 2022 to 2024.

The project was created as part of my learning and practice in **Excel data cleaning, Pivot Tables, data analysis, and dashboard development**.

## What I Worked On

* Cleaned and prepared the raw sales data for analysis.
* Identified and handled duplicate records, missing values, inconsistent formats, and incorrect entries.
* Used Excel functions and data preparation techniques to make the dataset analysis-ready.
* Created Pivot Tables to summarize sales across different dimensions.
* Built an interactive Excel dashboard using charts, KPIs, and slicers.
* Analyzed sales performance by:

  * Region
  * Retailer
  * Product
  * State
  * Sales Method
  * Time period

## Dashboard Highlights

The dashboard includes:

* Total Sales
* Units Sold
* Average Price per Unit
* Number of Orders
* Monthly Sales Trend
* Sales by Region
* Sales by Retailer
* Product Mix
* Sales Method Analysis
* Top-performing States

Slicers were added for **Region, Retailer, Sales Method, and Date Range** to make the dashboard easier to explore.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Excel Functions
* Data Cleaning

## Key Learning
Through this project, I practiced transforming raw sales data into a structured dataset and using Pivot Tables and visualizations to identify sales trends and compare business performance across different categories.
